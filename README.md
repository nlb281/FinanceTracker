## Общая информация о проекте `FinanceTracker`

- Реализованы операции `Create`, `Read`, `Delete` для категорий и транзакций. Операции `Update` пока нет.
- Backend написан на Go (`chi` + `sqlite`).
- Frontend реализован на `Vue 3` + `Vite` + `Vue Router` + `SCSS`.
- На frontend доступны просмотр, добавление и удаление категорий и транзакций (без `Update`).
- Авторизация (JWT/пользователи) в текущей версии не реализована, данные общие для всех запросов.
