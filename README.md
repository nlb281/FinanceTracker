# FinanceTracker Frontend

Frontend-часть приложения для учета финансов: показывает баланс/доходы/расходы, список транзакций и категорий, поддерживает добавление и удаление записей.

## Стек

- Vue 3
- Vite
- Vue Router
- scss

## Запуск проекта

npm install
npm run dev

Важно: backend должен быть запущен на http://localhost:8082 (запросы идут через /api прокси).
